## 00:10 — Deploy: study-assistant steps no longer gated

User finished the one-time study-assistant cloud setup and asked to drop the
`STUDY_ASSISTANT_ENABLED` repo variable gate. `deploy.yml` now always sets
up gcloud, deploys the study-assistant API (only when `apps/study-assistant/api`
or the workflow changed, or the service doesn't exist) and publishes
Firestore rules. Recorded as an addendum to the study-assistant ADR 0001.
Trade-off: if that cloud setup is ever undone, every Deploy run fails. The
GitHub variable itself is now unused and can be deleted.

## 00:20 — Fix: API deploy failed on env-var parsing

First real API deploy (run #32) failed before reaching Google Cloud:
`--set-env-vars` used `^@^` as the custom delimiter, which split the email
addresses at their `@`. Switched to `^;^`. Reproduced the original error and
confirmed the full fixed command parses locally (it then stops only at
authentication, which CI has).
