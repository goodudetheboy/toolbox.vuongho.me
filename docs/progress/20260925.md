# 2026-09-25

## Homepage redesign: 3D garage toolbox

- Replaced the card-list homepage with a three.js scene: garage (concrete
  floor, block walls, pegboard with hanging tools, paint-can shelf, LED
  shop light), butcher-block workbench, and a red powder-coated toolbox.
  Clicking the box swings the lid open (physical hinge sim with bounce off
  the stay strap) and flies the camera in. Inside on a foam insert:
  marker → PDF Redactor, microphone → Audio Transcriber, compass → Trip
  Planner (its needle swings to world north), plus loose screwdriver/nuts.
  Hover shows a card; click lifts the tool to the camera and navigates;
  touch uses tap-to-preview, tap-again-to-open. Tools can be dragged and
  tossed (cannon-es). Esc / "Close lid" / tapping the lid puts things back
  and shuts it.
- New deps in `apps/homepage`: `three`, `cannon-es`, `@types/three`.
- Decision recorded in [ADR 0006](adr/0006-homepage-3d-garage-toolbox.md).
- Verified in dev (open/hover/drag/close/launch, mobile 375×812 framing)
  and in the production build via `firebase-tools serve` (lazy chunk
  loads, renders, click opens, no console errors).
