## 13:50 — New tool: churn-machine

Added `apps/churn-machine` (bank account bonus deals, paycheck planner, account tracker); its own docs are in `apps/churn-machine/CLAUDE.md` and `apps/churn-machine/docs/`. Toolbox-wide pieces:

- `firebase.json`: new Firestore database `toolbox-churn-machine` (created in `us-central1` with gcloud today) with its rules, a `/churn-machine/**` rewrite for deep links, and a 10-minute cache header on `/churn-machine/deals.json`.

This push also redeploys the study-assistant API once, because `deploy.yml` changed.
- Homepage: new `coins` prop (a small stack of gold coins) in the 5th toolbox slot, with a matching SVG icon.
- Root `package.json`: `dev:churn-machine`.

Verified after the deploy: CI's refresh wrote 247 deals, the churn-machine rules were released to the new database, `/churn-machine/plan` deep-links, and production serves `deals.json` with `cache-control: public, max-age=600`.
