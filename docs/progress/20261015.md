# 2026-10-15

## 13:50 — New tool: churn-machine

Added `apps/churn-machine` (bank account bonus deals, paycheck planner, account tracker); its own docs are in `apps/churn-machine/CLAUDE.md` and `apps/churn-machine/docs/`. Toolbox-wide pieces:

- `firebase.json`: new Firestore database `toolbox-churn-machine` (created in `us-central1` with gcloud today) with its rules, a `/churn-machine/**` rewrite for deep links, and a 10-minute cache header on `/churn-machine/deals.json`.
- `deploy.yml`: refreshes churn-machine's deals before the build, and now also runs daily plus on manual dispatch, so the data stays fresh. Scheduled/manual runs skip the study-assistant Cloud Run deploy. New ADR: `docs/adr/0007-daily-scheduled-deploy.md`. This push also redeploys the study-assistant API once, because `deploy.yml` changed.
- Homepage: new `coins` prop (a small stack of gold coins) in the 5th toolbox slot, with a matching SVG icon.
- Root `package.json`: `dev:churn-machine`.

Verified after the deploy: CI's refresh wrote 247 deals, the churn-machine rules were released to the new database, `/churn-machine/plan` deep-links, and production serves `deals.json` with `cache-control: public, max-age=600`.

## 14:10 — churn-machine is installable

`firebase.json`: `/churn-machine/**` now gets `Cache-Control: no-cache` (same as study-assistant, for service-worker updates), replacing the `deals.json`-only rule. Details are in churn-machine's ADR 0004.

## 23:45 — Scheduled deploy: daily → weekly

At the user's request, the scheduled run of `.github/workflows/deploy.yml` is now weekly, on Mondays at 11:17 UTC (about 7am Eastern), instead of daily. Pushes to `main` still refresh churn-machine's deals in between. Cost wasn't the reason: the runs were already free (public repo, standard runners) and well within Hosting's free storage. Daily data just wasn't needed. Deal end dates and "ending soon" are computed in the browser, so they stay right during the week. Only brand-new or newly ended deals can lag by up to a week.

Docs: amended the toolbox-wide ADR 0007 (the filename still says "daily" so links keep working), the root and churn-machine CLAUDE.md, churn-machine ADRs 0001 and 0009, a code comment, and the churn-machine user guide.
