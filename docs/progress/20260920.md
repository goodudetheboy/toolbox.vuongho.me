# 2026-09-20

## Session start — architecture decided, monorepo scaffolded

Repo was empty (just `LICENSE`/`README.md`). Worked through the overall
architecture with the user in chat before writing any code:

- Single repo, npm workspaces, one app per tool
  ([0001](adr/0001-monorepo-npm-workspaces.md)).
- One shared GCP project `vuonghome` across all planned `*.vuongho.me`
  subdomains, not just this one
  ([0002](adr/0002-shared-gcp-project-vuonghome.md)). Checked
  `gcloud projects list` — `vuonghome` already exists and is clean
  (Firestore/Firebase not yet enabled on it, no mode locked in).
- Homepage needs to link to tools and tools need a "back to toolbox" link,
  which forced resolving an open routing question in favor of one Firebase
  Hosting site for the whole domain, with a build-time combine step doing
  path-based routing between apps rather than per-app subdomains
  ([0003](adr/0003-single-hosting-site-path-routing.md)).
- First tool: a PDF redactor (upload → flatten pages to images → draw black
  boxes → export new PDF). Decided fully client-side, no backend — a
  redaction tool that uploads the original document to a server undercuts
  its own purpose ([0004](adr/0004-pdf-redactor-fully-client-side.md)).
  Library choices: `pdfjs-dist` for rendering, `pdf-lib` for export
  rebuild, hand-rolled canvas for the rectangle drawing — normalized
  `[0,1]` coordinates so editing-scale and export-scale (150 DPI, PNG) are
  decoupled ([0005](adr/0005-pdf-redactor-library-choices.md)).
- Backend/Firestore stay opt-in per tool, added only when a specific tool
  needs them, namespaced `toolbox-<tool>-api` / `toolbox-<tool>`, region
  `us-central1` ([0006](adr/0006-per-tool-backend-and-firestore-naming.md)).

Scaffolded via a Plan-mode approved plan: root `package.json` (npm
workspaces), `tsconfig.base.json`, `scripts/combine-dist.mjs`,
`firebase.json`/`.firebaserc` (single `toolbox` Hosting target),
`.github/workflows/deploy.yml`, `apps/homepage` (full Vite+React+TS stub
with a tool-list landing page), and started `apps/pdf-redactor`.
