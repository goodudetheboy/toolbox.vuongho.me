## Toolbox-wide CLAUDE.md rule added: test production builds for Worker-sensitive changes

While building pdf-redactor's export pipeline, a change that worked in
`npm run dev` shipped a real crash in the actual production build (Web
Worker/module-loading behavior differs between Vite dev mode and the
production bundle — see
[apps/pdf-redactor/docs/progress/20260920.md](../../apps/pdf-redactor/docs/progress/20260920.md)
for the incident). Added a rule to the root `CLAUDE.md` — test the actual
production build (`npm run build && npm run combine && npx firebase-tools
serve`), not just dev mode, before pushing anything touching `new
Worker(...)` or dynamic imports. This applies to every tool, not just the
one that surfaced it, which is why it lives in the root `CLAUDE.md` rather
than one app's own.
