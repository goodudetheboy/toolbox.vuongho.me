pdf-redactor, audio-transcriber and trip-planner each had the same
"click then immediately revoke the blob URL" download code, which fails on
mobile browsers. Fixed in each app (details in their own progress logs).
Apps stay independent, so no shared helper was introduced.

PDF Redactor moved to real URL paths (its own ADR 0009 / progress log);
root `firebase.json` now rewrites `/pdf-redactor/**` to its `index.html`,
alongside the existing trip-planner rewrite, so deep links survive a reload.
