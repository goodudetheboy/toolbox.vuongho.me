## 20:45 — Hosting SPA rewrite for trip-planner

Added `rewrites: [{ source: "/trip-planner/**", destination: "/trip-planner/index.html" }]`
to `firebase.json` so trip-planner's new real URL paths
(`/trip-planner/trips/:id`, etc.) survive a reload / direct link. Rewrites
only apply when no static file matches, so assets and the other tools are
unaffected — verified with `firebase-tools serve` (which, unlike
`headers`, does apply rewrites locally). Why it's needed:
`apps/trip-planner/docs/adr/0003-real-url-paths.md`. Other tools can add
their own rewrite the same way if they adopt client-side paths.
