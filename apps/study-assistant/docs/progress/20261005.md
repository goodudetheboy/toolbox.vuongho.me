## 01:55 — Concept-level scoring

ideas, scores each 0-100 (paraphrase fine, every detail counts), and returns

skipped in "A, B and C". Hinted words get no credit. Percent weighted by idea
length (`gradeIdeas`, tested). Result label now "N% of the ideas". On-device
word match is only the offline fallback. ADR 0001 addendum; app CLAUDE.md
summary refreshed (also: notes are cleaned up, hints are silent).
Verified: api tests 5/5, tsc, mock flow end to end. Open: watch real
grading on first use (idea splits, how strict it is).
