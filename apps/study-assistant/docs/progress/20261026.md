## 23:45 — Plainer new-part placeholder, HEIC photos

- New-part editor placeholder is now just "Enter your notes here…" (user asked).
- Phone photos in HEIC (iPhone, Samsung "high efficiency") failed in the part editor on
  Chrome: `createImageBitmap` can't decode HEIC, and untyped HEIC files were filtered out.
  New `src/lib/decodeImage.ts`: browser decode first, then lazy `heic-to` (libheif wasm,
  ~3 MB / 776 kB gz) as fallback; `isImageFile` accepts `.heic/.heif` by name; file inputs
  accept `image/*,.heic,.heif`. Used by part pictures and the photo import (which now also
  gets shrunk instead of sending the raw HEIC). The decoder chunk is excluded from the PWA
  precache (`globIgnores`), so only people who pick a HEIC photo download it.
- Not verified on a real phone with a real HEIC file (no browser in this container).
