## 16:41 — Edit/add/move parts, empty notes, pictures in parts

- **Edit parts mode** on the note (⋯ → Edit parts): edit, delete, ▲▼ move, + between
  cards to insert. "Add a part" card at the end of the list; "Add a part after this" in
  a part's ⋯ menu. New-part editor = the existing editor + a "Put it" picker.
- **Start empty**: a new-note option with just a name/subject, no Gemini. Notes can now
  have zero parts (deleting the last part is allowed); empty state on the note screen.
- **Pictures**: paste / drag-and-drop / 🖼 button in the editor; shrunk WebP stored as
  `notes/{id}/images/{imgId}` docs, referenced as `![](img:ID)`. Shown as photo prints.
- **Integration checks**: grading/hints/tags/Listen only see `tokenize()` words, which
  skip pictures (unit-tested); `textHash` ignores pictures so old tries' marks and exam
  tags survive adding one (unit-tested); everything per-part is keyed by part id, so
  moving parts is safe; empty notes hidden from exam picking; "1 part" plural fix.

  (`parts-edit`, mock build) since Chromium can't run in this container.
