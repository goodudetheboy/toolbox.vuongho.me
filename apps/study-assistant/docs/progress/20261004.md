# 2026-10-04

## 23:59 — Study assistant ("Study with Biggu") built

New tool for a nursing student to memorize notes by reciting them. Design in
[ADR 0001](../adr/0001-study-assistant-architecture.md); one-time console
setup in [SETUP.md](../SETUP.md).

What's in:
- Add a note by pasting, PDF/Word, or photos → `/prepare` (Gemini
  `gemini-3.8-flash`) splits it verbatim into Markdown parts, bolds key
  phrases if the note had no bold, names the subject and lists hard terms.
  Verbatim check + one retry for pasted/Word text.
- Recite a part: mic → Gemini Live `gemini-3.5-transcribe-live` (ephemeral
  token, custom vocabulary), on-device word tracking and pause detection;
  3 s pause → next word shown and spoken (`gemini-3.8-flash-lite-tts`),
  still stuck → next three. Done → `/score` (Gemini) ∪ on-device match →
  % remembered with missed/hinted/"say it clearer" words marked.
- Firestore `toolbox-study-assistant` sync, allowlist of two emails (rules +
  API). English UI, progressive disclosure, scrapbook style, Biggu the
  brown-grey tabby (SVG, 8 moods).

Decisions along the way (all in ADR 0001): API called directly at its
`run.app` URL rather than via a Hosting rewrite (60 s timeout); pause
detection on device with an adaptive noise floor (a fixed threshold never
went quiet under steady background noise in testing); headings aren't
recited; correctly-said words stay unhighlighted in the result so misses
stand out. User asked to drop Vietnamese UI/translation — UI is English only.

Verified: API unit tests (3) and matcher tests (6) pass; API smoke-tested
locally (health, 401 without/invalid token, CORS allow/deny); Gemini request
bodies captured from the SDK and checked; full UI flow in iPhone-13
emulation against `VITE_MOCK=1` fakes (add → split → read → recite → hint
1 word then 3 words → score → next part → back/forward); production bundle
served with the Hosting rewrite: deep link renders, lazy Gemini SDK and
mammoth chunks load, mic AudioWorklet delivers frames.
