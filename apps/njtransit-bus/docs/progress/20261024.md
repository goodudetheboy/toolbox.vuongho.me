# 2026-10-24

## 09:15 — First version: setup screen, live board, API

Built from the "Bus Times" design canvas the user approved (white with NJ Transit blue, giant type; heading back inverts with a color wipe; soonest bus big, scroll-snap to alternating tiles; timetable times marked).

- API (`api/`): GTFS timetable in memory + BUSDV2 live departures, matched by trip id; stops within 200 m count as the same place so flipping works across the street; Port Authority gates from `lanegate` or the timetable. Unit tests for time handling, stop search and departures (service days, after-midnight trips, calendar exceptions, gates).
- Checked against the real API before building (see ADR 0001's Context): stop numbers work in getBusDV, trip ids match GTFS, how "tracked" shows up, gate format.
- App: Setup (search by name/number, NEAR ME) and Board. Verified in a headless browser against the local API with live data, both directions (48th St at Bergenline ⇄ Port Authority): countdowns, SCHED tiles, gate 200-1, "FROM" for 159s leaving from the stop around the corner, the wipe.
- Deployed `toolbox-njtransit-bus-api` by hand once to check it on Cloud Run (CORS, live data in ~0.6 s); CI deploys it from now on. Secrets `njtransit-bus-username` / `njtransit-bus-password` created in Secret Manager.

Decisions: ADR 0001.
