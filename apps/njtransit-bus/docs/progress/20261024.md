# 2026-10-24

## 09:15 — First version: setup screen, live board, API

Built from the "Bus Times" design canvas the user approved (white with NJ Transit blue, giant type; heading back inverts with a color wipe; soonest bus big, scroll-snap to alternating tiles; timetable times marked).

- API (`api/`): GTFS timetable in memory + BUSDV2 live departures, matched by trip id; stops within 200 m count as the same place so flipping works across the street; Port Authority gates from `lanegate` or the timetable. Unit tests for time handling, stop search and departures (service days, after-midnight trips, calendar exceptions, gates).
- Checked against the real API before building (see ADR 0001's Context): stop numbers work in getBusDV, trip ids match GTFS, how "tracked" shows up, gate format.
- App: Setup (search by name/number, NEAR ME) and Board. Verified in a headless browser against the local API with live data, both directions (48th St at Bergenline ⇄ Port Authority): countdowns, SCHED tiles, gate 200-1, "FROM" for 159s leaving from the stop around the corner, the wipe.
- Deployed `toolbox-njtransit-bus-api` by hand once to check it on Cloud Run (CORS, live data in ~0.6 s); CI deploys it from now on. Secrets `njtransit-bus-username` / `njtransit-bus-password` created in Secret Manager.

Decisions: ADR 0001.

Open:
- Gate text is shown as "200-1" (NJ Transit's own format in its docs); unconfirmed what the suffix means on the signs at Port Authority.
- The homepage's 3D toy bus couldn't be looked at here (no GPU in the container); only the list icon was checked.
- Not a PWA yet (no offline/install); the board is meant to be opened fresh.

## 09:40 — No route lists for terminals in the stop picker

At the user's request: a stop with more than 6 routes (Port Authority has ~65) now shows just its number in search results and under the picked stop, instead of a long route list. Smaller stops still show headsign + routes, which is what tells the two sides of a street apart. Login tokens: already cached per instance for 12 h (re-login only on expiry or "invalid token"); unchanged.

## 09:50 — Giant type clipped on a real phone

The user's phone (Brave, ~410 px wide) showed "NOW" wider than the screen, so the whole page scrolled sideways and clipped the left edge. Shrunk "NOW" (34vw, max 150px) and the timetable clock (28vw, max 120px; it overflowed too), and set `overflow-x: clip` on the page so oversized type can never shift the layout again. Measured every big-number variant (NOW, 1 and 2 digits + MIN, 12:40 AM, gate) at 320/360/390/412 px: all fit inside the padding.
