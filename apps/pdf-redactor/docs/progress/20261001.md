# 2026-10-01

## 12:00 — Fix export download on mobile

The export download helper revoked its blob URL synchronously right after
`anchor.click()` and never attached the anchor to the DOM. Desktop browsers
tolerate that, but mobile Safari/Chrome start the blob fetch asynchronously,
so the download silently failed on phones. Now the anchor is appended to
`document.body` before clicking and the URL is revoked after 60s. Same fix
applied to every tool with an export (see root progress log). No ADR needed.
Not verified on a real phone from this session — worth a check on iOS Safari.

## 13:30 — Mobile-friendly editor: zoom/pan, Move/Draw, bottom bar

Rebuilt the editing surface for phones, see
[ADR 0008](../adr/0008-mobile-editing-zoom-pan-and-bottom-bar.md):
- `PageCanvas`: page in a scroll box with in-app pinch-zoom (1×–5×) and
  two-finger pan; one finger pans or draws per a new Move/Draw mode
  (touch defaults to Move). Preview re-renders sharp at the zoomed size
  (capped at 10M px for iOS). Pointer capture so sliding off the edge
  doesn't end a box; tap-sized boxes ignored; touch hit slop; bigger
  delete button kept on screen. Ctrl+wheel zoom on desktop.
- New `EditorBar` replaces `Toolbar` + `PageNav`: one sticky bottom bar
  with page nav, mode toggle, Undo, Clear (confirms now), and one Export
  button with a Fast / Best quality menu.

Verified in headless Chromium with iPhone 13 / 320px emulation and CDP
touch events: pinch zoom + re-render, one-finger pan, draw, pinch never
leaves a stray box, tap-select + delete, export download; plus desktop
mouse drawing. Not tested on a real iOS device.
